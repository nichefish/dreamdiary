# Prospective 화면 마이그레이션 스펙

## `/keep` Keep 전수관리

**Vue 구현**: `app/frontend-vue/src/features/prospective/keep/KeepPage.vue`

전 범위 `prospective_keep(scope=all)`를 진행과 종결 그룹으로 나누어 표시한다. 진행은 `OPEN`·`PENDING`, 종결은 `RESOLVED`·`FAILED`·`EXPIRED`·`DROPPED`이며 완료는 녹색 `완료`, 실패는 빨간 `실패`, 만료는 노란 `만료`, 내려놓음은 회색 `내려놓음` 배지와 대응 아이콘으로 구분한다. 제목·본문 검색, 말머리·태그·기한 지남·중요 필터, 태그클라우드, 신규 등록, 제목 클릭 수정, 체크박스 즉시 완료와 행 컨텍스트 메뉴를 제공한다.

진행 그룹은 유효 기한 오름차순이며 기한이 없는 항목은 맨 아래에서 서버 순서(`sortOrder` → `id`)를 유지한다. 종결 그룹은 서버 순서를 유지한다. 유효 기한은 제목 뒤에 표시하고, 지난 기한의 미종결 항목은 경고색과 지난 일수를 표시한다. 종결 항목은 라이프사이클 판단 근거가 남도록 날짜만 표시하고 남은 일수는 표시하지 않는다. 등록일은 행 우측에 `yyyy.MM`으로 표시한다. 선택한 말머리는 제목 앞에 말머리 색상의 배지로, 태그는 제목 뒤에 카테고리와 이름으로 표시한다.

말머리·태그·검색어·기한 지남 필터는 전 범위 목록에 AND로 적용하며 필터 변경만으로 서버를 재조회하지 않는다. 「기한 지남」은 지난 기한의 미종결 항목만 남기고 종결 섹션을 숨기며 라이프사이클을 변경하지 않는다. 「중요」는 중요(`IMPRTC`) 상태 항목만 남기며 진행·종결 섹션을 모두 유지한다. 중요 항목은 진행 행에서 제목 앞 노란 별(`bi-star-fill text-warning`)과 굵은 제목, 종결 행에서 회색 별로 표시하고 정렬(`sort_order`)은 바꾸지 않는다. 태그클라우드와 행 태그는 같은 `TagContextMenu`를 사용해 필터를 토글하거나 `PROSPECTIVE_KEEP` 태그 프로필을 연다. 말머리 필터는 활성 개인 선택지가 있을 때 표시한다. 등록·수정 모달 종료 후 목록과 태그클라우드를 함께 재조회한다.

상단에는 `Project 미지정`, `전체`, 사용자 `OPEN` Project별 탭을 전역 순서대로 표시한다. 비`OPEN` Project는 관리 모달에 보존하고 탭에서 제외한다. 기본 탭은 `Project 미지정`이며 `전체`는 연결 여부와 무관한 전 범위를 유지한다. Project 범위는 다른 필터와 AND로 결합한다. Project 관리 행은 lifecycle 배지와 위·아래 이동 버튼을 직접 표시하고 수정·lifecycle·삭제는 컨텍스트 메뉴로 제공한다. 추가 폼은 목록 상단, 수정 폼은 선택 행 바로 아래에 표시하며 해당 행을 강조한다. Keep 행의 `Project로 이동` 메뉴는 현재 단일 소속을 표시한다.

## Keep 등록·수정 모달

**Vue 구현**: `app/frontend-vue/src/features/prospective/keep/modals/ProspectiveKeepRegistModal.vue`

- Bootstrap `modal-xl`, 폼 `#prospectiveKeepRegistForm`
- PC에서는 Project·말머리·제목·수정 순서를 한 행에 표시하고 모바일에서는 세로로 표시한다. 말머리가 없으면 제목이 해당 영역까지 확장한다. 제목은 유일한 필수값(최대 100자, DB `VARCHAR(200)` 범위 내)이며 공통 필수 표시를 붙인다.
- 말머리는 `PROSPECTIVE_KEEP` 개인 활성 선택지를 사용하며 정상 빈 목록이면 필드를 표시하지 않는다.
- 일시(`#dateText`)와 위치(`#location`)는 200자 자유 텍스트다.
- 위치는 Project와 분리된 전체 행을 사용한다.
- 유효 기한(`#expireDt`)은 일시에서 파생한 단일 날짜이며 readonly 입력·달력·기한 추출 버튼으로 변경한다.
- 일시와 유효 기한은 같은 행에 표시한다.
- 본문과 태그를 함께 편집한다.
- 푸터 저장 왼쪽 `미리보기` 버튼은 작성 중 본문을 `/journal/entry/preview-pop` 새 창에 렌더해 편집기 밖에서 확인한다(미저장). 미리보기 창은 제목 아래에 일시·유효 기한·위치·Project·태그 메타(값이 있는 항목만)를 두고, 본문은 좌우 여백 칸 없이 표시한다.
- 등록 성공은 호출 화면의 Keep 목록을 갱신한다.

저널 화면에 표시되는 `JournalAsideKeepCard`와 그 마운트 계약은 [저널 화면 스펙](../journal/screen-spec.md)이 소유한다.

## Keep 최근 완료 표시

✓ 웹의 목록 순서는 진행 중 → 최근 완료 → 나머지 종결이다. 최근 완료는 `RESOLVED`이며 서버 완료 시각부터 경과 시간이 0 이상 1시간 미만인 항목을 최신 완료순으로 표시한다. 처음 5건을 표시하고 6건 이상이면 `더 보기`로 전체를 펼치며 `접기`로 5건에 돌아간다. 시각 미확인 완료는 나머지 종결에 포함한다. Project·검색·필터 조건은 모든 그룹에 동일하게 적용하고 최근 완료가 없으면 해당 그룹을 숨긴다. 앱은 진행 중·기한 보기 하단의 접힌 `최근 완료 N건`과 종결 보기 상단 그룹을 사용한다([모바일 화면 스펙](../mobile/screen-spec.md) §4.14).
